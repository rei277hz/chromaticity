# 共享与动画 Grade

**Grade** 数据块保存权威的 Linear、Tone 和 Color 设置。着色器与合成器 Grade
节点可共用同一数据块，因此在任一编辑器中修改都会更新所有读取者。Grade Stack
拥有自己的有序条目列表，每个条目引用一个共享 Grade。

## 创建与复用 Grade

新建 Grade 节点尚未选择 Grade 数据块，显示默认值的控件会被禁用。编辑前，请用
选择器指定已有 Grade，或通过 **新建调色** 创建一个。选择相同数据块即可与其他
节点共享设置。已选择 Grade 时，新建调色会创建独立副本，适用于只有一个节点
需要不同设置的情况。重命名只会改变名称。

从节点解除 Grade 关联只会清除该节点的引用并恢复默认设置，不会删除数据块。Stack
条目可解除关联或移除，引用的 Grade 仍会保留。Blender 的伪用户设置可让未使用的
数据块在保存文件后继续存在。

## 为节点自有 Grade 制作动画

右键 Grade 节点并选择 **转换为节点自有调色**。Next 会把当前设置复制到节点上，
使其独立于共享 Grade。这种模式适合跟随 Blender 时间轴变化的变换。Linear、Tone
及 Stage 3 数值字段可使用 Blender 的普通关键帧命令或 Auto Key。离散的 Tone Peak
选择为静态设置。

动画属于所在着色器或合成器节点树的 Action。复用材质或节点组会让所有用户共享此
动画。要恢复共享设置，请选择 **转换为数据块调色**。Next 会根据当前帧值创建 Grade
数据块，并移除此节点的 Grade 动画；撤销可恢复之前的节点自有动画。

无论正向还是反向播放，如果当前帧的调色结果尚未就绪，节点自有 Grade 都可以
显示本次播放中最近完成的结果。**Updating** 表示显示的调色结果仍在追赶播放头。
停止播放或拖动时间轴后，节点会按所选帧的准确设置更新。

节点自有 Grade 不提供 Bake 控件，因为动画中的数值会随时间变化，并通过渲染预检
求值。共享 Grade 与 Grade Stack 支持 Bake，详见[渲染与烘焙](render-methods.md)。

## 保存与渲染

扩展会在载入文件后以及渲染前协调内核。交互期间，准备替换结果时可暂时显示上一
个完整结果，并标记 **Updating**。只有当前的完整结果可用于渲染。若当前准备失败，
节点会显示保留 alpha 的洋红错误输出，渲染预检会停止受影响的帧。
