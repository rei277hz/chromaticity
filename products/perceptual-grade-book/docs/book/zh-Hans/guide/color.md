# Color

Color 是 Stage 3，在 Linear 和 Tone 之后调整感知外观，并通过影调、彩度和色相
进行平滑控制。侧栏将数值控件分为 **J**、**C**、**Adaptance** 和 **Warp**。

## J 与 C 响应

J 改变感知明度响应，C 改变彩度响应。每一类都具有四个影调锚点：Shadows、
Midtones、White 和 Highlights。每个锚点上的低／高彩度权重用于调整径向贡献，
a/b 值用于调整对立色方向。Fit 控制影调间的平滑融合；Global C Gain 调整整体
彩度倍率。

建议先从较小的数值开始。J 可改变对比或突出主体；C 可增强或减弱色彩。调整时
同时检查中性色和高彩度颜色，因为较大的改动可能影响目标之外的颜色。

## 选择性 Adaptance

Adaptance 在 Shadows、Midtones、White 和 Highlights 处设置 a/b 目标坐标。其
彩度参数决定修正达到一半影响的位置。它用于在选定影调范围内改变外观，不是
Linear 的白平衡控件。

a、b 两个坐标共同表示一个径向目标。若请求超出有效范围，Next 会沿原方向缩短
该目标，使校准后的锥体响应保持有效，而不会分别截断 a 和 b。**Limited** 表示
当前采样请求（例如动画值）在求值时需要缩短。Shadows、Midtones、White、Highlights
的常用滑块范围依次为 ±4、±10、±20、±25，拖动增量为 0.01；键入值不会按此增量
取整。这些是编辑范围；有效的径向边界取决于影调
锚点。非有限数值请求会显示失败。

## Warp 色网

Warp 在四个影调锚点各提供六个循环色相手柄：red、yellow、green、cyan、blue
和 magenta。彩度值是以档为单位的 log2 变化；色相值是存储的角度偏移；Scale
值也以档为单位，用于确定 H–K 修复之后使用的正缩放量。控件会沿循环色网及
影调锚点间插值。当前界面使用数值字段，不提供可拖动的图示。

相邻目标色相始终保留至少 4° 的循环间隔，包括 magenta 与 red 之间的接缝。
编辑时会固定当前色相，并在需要时沿任一方向推动相邻手柄。**Auto** 标记因此
被自动移动的色相，其提示会注明发起调整的色相。再次编辑发起色相时，会一起求解
其自动返回位置，在满足相邻间隔的前提下尽量返回保存的位置；暂时无法返回时，
该关系仍会保留。若手动编辑其中一个色相，会从其当前位置开始，并且只解除该色相
与先前自动调整的关系。

修改 Peak 会清除自动返回关系，并一起解析新的色相几何与 Adaptance 限制。
共享 Grade 的自动关系可跨帧保留；节点自有 Grade 则在实际帧或子帧改变时清除。
若插值后的动画值不满足色相间隔，求值会将角度投影到有效范围，并显示
**Limited**，不会改写保存的数值或关键帧。

修改 Warp 后应检查完整图像。求值使用 Tone 后冻结的选择器，然后依次执行 J/C
响应、Warp 色相／彩度并选择 Scale、选择性 Adaptance、H–K 修复，最后将 Scale
应用于修复后的对立色坐标，并将 Scale 的平方应用于带符号能量。该顺序符合参考模型的先守护、后缩放
约定。RGB 色域包含是独立的输出边界操作。

节点自有 Grade 的 Stage 3 数值可使用 Blender 关键帧。共享 Grade 和 Stack 条目
为静态。Stack 会将所有启用的正向 Grade 采样到单一的 33³ 预览，再细化为 65³
最终变换；详见[Grade Stack](inverse-stack.md)。
