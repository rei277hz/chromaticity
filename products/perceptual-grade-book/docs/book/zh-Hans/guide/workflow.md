# 分三个阶段调色

> **保留版本：** 本使用章节及截图描述 1.23.2，仍滞后于最新模型。当前参考见[理解模型](../theory/structure.md)；这些控件并非 Next 未来的 Warp 实现。

用同一套流程处理两张图像。示例 A 是 SDR，示例 B 是 HDR；它们在本书中始终分别位于左侧和右侧。每组示例都展示同一个控件，但调色意图不同。

先让两张图像的光照恢复中性，并平衡曝光。细调 SDR 图像较柔和的色彩关系，同时保留 HDR 图像中漫反射表面与明亮高光之间的层次。在 Tone 中，为 A 建立 S 形反差曲线，并用类似伽马的曲线提亮 B 的暗部。将这些调整带入 Color，再用相同控件配合每张图像自己的影调分布进行细调。

每段演示都从上一段演示的结果继续。整个流程中保持图像、裁切、视图变换和曝光设置不变；六项 Color 操作都应保留已完成的 Linear 与 Tone 调整。并排动画比较的是两个独立示例，而不是前后对比画面。

在 [Linear](linear.md) 中，让应该为白色的部分真正显示为白色，再对照色卡检查曝光与色彩关系。在 [Tone](tone.md) 中塑造反差并提亮阴影，然后比较 SDR 与 HDR 波形。在 [Color](color.md) 中，按所选色调区域调整明度、彩度、Adaptance 与色相。

方形录像一边显示图像，一边显示 Blender 中 Perceptual Grade 扩展的控件面板。它们以录制速度循环播放；如果一项调整先结束，其最后一帧会停留，等待另一段完成。短暂停留结束后，每组录像会自动再次播放。

这些都是 SDR 与 HDR 源图像的屏幕录像，两者都已转换为网页使用的 sRGB。HDR 示例展示的是调色和示波器行为；本网页无法重现 HDR 显示器的峰值亮度。

标有 Dummy recording 的面板仍使用随附的临时视频片段。对应说明介绍了预期操作；替换源录像后，该标签会自动消失。
