# 分三个阶段调色

Grade 由三个相连的阶段组成：**Linear** 设置曝光、白平衡和整体色彩关系；
**Tone** 将场景亮度映射到感知明度；**Color** 按影调与色相调整明度和彩度。
建议按此顺序操作，并在每个阶段后检查完整图像。

先选择中性参考，并确保输入图像已正确解码。在 Linear 中校正偏色并设置整体
亮度，不要把高光一律推到白色。在 Tone 中，根据图像动态范围放置黑、阴影、
中间调、白和高光锚点。在 Color 中进行选择性调整，同时观察肤色、中性色和
高彩度颜色。单个 Grade 是全局变换，无法补偿局部光照或错误的输入色彩配置。

Next 在侧栏中提供完整的 Stage 3 数值控件。**J** 按低／高彩度及对立色方向
调整明度响应。**C** 使用相同驱动因素调整彩度响应，并提供全局彩度增益。
**Adaptance** 为 Shadows、Midtones、White 和 Highlights 设置对立色空间目标，
并共享半影响彩度。**Warp** 在四个非黑色调锚点上使用六点循环色网：彩度以档为
单位，相位显示存储的角度偏移，Scale 也以档为单位。各类控件会在影调间平滑
插值。目前没有可拖动的 Warp 图示，请使用数值字段。

数值模型使用冻结的 Tone 后选择器及带符号能量。执行顺序为 J/C 响应、Warp
色相与彩度并选择正 Scale、选择性 Adaptance、H–K 修复，最后将 Scale 应用于
修复后的对立色坐标，并将 Scale 的平方应用于能量。H–K 守护在 Scale 之前执行。若需要，RGB 输出边界
会另行把结果投影到受支持的 RGB 色域内。

比较调色版本时，保持曝光、视图变换和输入解码方式一致。场景线性值可以高于
显示白；应通过预期的显示变换判断，而不是截断源高光。
