# 外观坐标与调色

阶段 1 在扩展中仍是对线性 RGB 的运算，在 DCTL 中则是对应的线性 XYZ 运算。进入阶段 2 之前，校正后的颜色先进入 modCAM16。随后 Tone 与 Color 在外观坐标上工作，阶段 3 结束后再解码回线性颜色。本章介绍这套表示，尤其是 Color 控件所使用的那几个坐标。

本部分描述 `libraries/perceptual-grade-reference` 中的解析参考模型。若某条陈述只适用于 1.23.2 的 DCTL 与 Blender 版本——它的 Hue Concentration 控件、Adaptance Strength 控件、`0.4·U(J_A,h)` 驱动分类阈值，以及它随包发布的查找表——本章会明确说明。若解析参考自身的适用范围比产品更窄，本章也一并指出。没有这条界线，一段"属于旧版本"的陈述读起来就像一段过时的陈述，而两者需要完全不同的处理。

modCAM16 是 CAM16 家族中的修订颜色外观模型。它描述颜色在给定观察条件下的样貌，并把明度、彩度强度与色相区分开来。Perceptual Grade 使用其修订后的关系式以及 Helmholtz–Kohlrausch 补偿——后者描述彩度对感知明度的贡献。

主明度坐标是 \(H\)，也写作 \(J_{\mathrm{HK}}\)。它已包含 H–K 贡献，界面中标为 J。Tone、Lightness J 曲线、波形显示与色调选择都使用这个坐标。非彩色分量 \(J_A\) 进入饱和度计算和逆域保护。

彩度 \(C\) 表示在调色对色平面中离开中性色的距离；色相 \(h\) 给出绕该平面的角度。对应的直角坐标是 \(a=C\cos h\) 与 \(b=C\sin h\)。彩度控件改变半径，色相旋转转动该平面，方向板使用其带符号的 \(a\)、\(b\) 坐标。

固定 \(h\) 时向外移动增大 \(C\)；绕平面移动改变 \(h\)；移动 \(a\) 或 \(b\) 可能同时改变两者。Lightness J 调整改变 \(H\)，Chroma \(C\) 调整改变半径，Adaptance 平移对色位置，色相旋转转动它。Tone 曲线决定每个操作在不同输入明度上的作用强度。

$$
H=J_{\mathrm{HK}}=\sqrt{J_A^2+66C}\quad (J_A\ge0),\qquad
C=\sqrt{a^2+b^2},\qquad h=\operatorname{atan2}(b,a).
$$

该恒等式只在非负非彩分支上成立。低于该分支的带符号工作颜色落到 H–K 对的另一侧，同一个 \(C\) 在那里有第二个更小的明度解。记 \(b=\sqrt{66C}\)，参考实现不丢弃符号，而是以该中点为轴做反射：

$$
H=2b-\sqrt{J_A^2+b^2}\quad (J_A<0).
$$

因此 \(H\) 在穿过 \(J_A=0\) 时保持连续，在该处取值为 \(b\)，而不是塌缩到 \(\sqrt{66C}\)。这一带符号映射的逆是能量 \(E=J_A|J_A|\)，单独贯穿 Color 阶段传递；绝不用四舍五入后的 \(H^2\) 减去 \(66C\) 反推。

调色平面以实际 \(C\) 作为半径。不要用教科书里的 CAM16-UCS \(M'\) 或其他压缩均匀空间坐标替代这些 \((a,b)\) 值。共享的术语并不意味着数值尺度可以互换。

曲线使用 \(j=H/100\)。参考白的中性色有 \(H=100\)；HDR 明度可以继续高于它。默认 Reference Nits = 203，适应亮度 \(L_A=20.3\) nit，暗环境常数为 \(c=0.525\) 与 \(N_c=0.8\)。编码与解码共用同一色相偏心率表达式，其中包含 \(-0.1475\sin h\)。

其余观察常数为背景与测试白：参考实现固定背景亮度 \(Y_b=10\)，并以 \(100W\) 归一化锥响应，同时折现光源色。早期文档把背景写成 20.3 nit。该值与参考实现和当前产品都不符，而它会改变每一种颜色的编码响应，因此值得直说，而不是留给实现去猜。

解析参考只接受一种配置：Grade 白点 D65、Reference Nits 203。它的入口对任何其他白点或参考值都会直接报错，因为其边界表正是为这一对参数生成的。DCTL 与 Blender 产品提供 [工作白点](../guide/working-white.md) 中描述的八种白点预设和更宽的 Reference Nits 范围；那些设置属于产品，不属于这一分析。

有两个明度坐标，不能混为一谈。\(H\) 即 \(J_{\mathrm{HK}}\)，含 H–K 项，是 Tone 重映射的对象。非彩色分量 \(J_A\) 进入饱和度比与逆域保护，并以带符号能量而非重算值的形式传递。

[保持饱和度的影调曲线](tone.md) 在重映射明度的同时维持阶段 2 的不变量。[按影调塑形的色彩算子](color.md) 再按色调区域混合各项调整。[求值与插值](evaluation.md) 随后说明有界 H–K 保护以及解析、原生节点与采样三种实现。

对带符号工作颜色，实现先用中性偏移抬起负锥响应，再分别变换抬起的信号与该偏移，最后减去变换后的偏移。精确复位保留其恒等旁路。Color 之后由保护处理另一条实非彩能量边界。完整的模型与工程参考见[致谢](../reference/credits.md)。
