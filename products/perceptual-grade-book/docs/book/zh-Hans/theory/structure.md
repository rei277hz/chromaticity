# 外观坐标与调色

阶段 1 是线性颜色变换。参考实现随后把输入修复到原生 AP1 立方体中，再编码到 modCAM16。Tone 与 Color 在外观坐标上工作；阶段 3 结束后，RGB 导出执行立方体约束和解码。本章介绍这套表示，尤其是 Color 控件使用的坐标。

本部分描述 `libraries/perceptual-grade-reference` 中当前的解析模型。归档的 1.23.2 控件、操作说明与测量会单独标明。冻结的 Blender 实现保留先前的 Warp 顺序；Next Blender 尚未实现 Warp，未来将采用修正后的参考模型。因此，产品功能和历史版本都需要明确标注适用范围。

modCAM16 是 CAM16 家族中的修订颜色外观模型。它描述颜色在给定观察条件下的样貌，并把明度、彩度强度与色相区分开来。Perceptual Grade 使用其修订后的关系式以及 Helmholtz–Kohlrausch 补偿——后者描述彩度对感知明度的贡献。

带符号明度坐标是 \(H\)，也写作 \(J_{\mathrm{HK}}\)。它已包含 H–K 贡献，界面中标为 J。Lightness J 调整改变这个坐标。Tone 与影调选择使用非负幅值 \(M=\sqrt{J_A^2+66C}\)，在 \(J_A\ge0\) 时它等于 \(H\)。非彩色分量 \(J_A\) 进入饱和度计算与 H–K 修复。

彩度 \(C\) 表示在调色对色平面中离开中性色的距离；色相 \(h\) 给出绕该平面的角度。对应的直角坐标是 \(a=C\cos h\) 与 \(b=C\sin h\)。彩度控件改变半径，色相旋转转动该平面，方向板使用其带符号的 \(a\)、\(b\) 坐标。

在彩度平面中，固定 \(h\) 时向外移动增大 \(C\)；绕平面移动改变 \(h\)。移动 \(a\) 或 \(b\) 可能同时改变两者。Lightness J 调整改变 \(H\)，Chroma \(C\) 调整改变半径，选择性 Adaptance 改变对色位置和非彩能量。影调选择器决定各操作的作用强度。[Warp 饱和度面板](color.md) 使用另一套紧致坐标，还取决于非彩能量。

$$
H=J_{\mathrm{HK}}=\sqrt{J_A^2+66C}\quad (J_A\ge0),\qquad
C=\sqrt{a^2+b^2},\qquad h=\operatorname{atan2}(b,a).
$$

该恒等式只在非负非彩分支上成立。负非彩值使用反射分支。记 \(B=\sqrt{66C}\)，它与对色坐标 \(b\) 不同：

$$
H=2B-\sqrt{J_A^2+B^2}=2B-M\quad (J_A<0).
$$

两个分支在 \(J_A=0\) 处连续相接，此时 \(H=B\)。这里的有彩点仍然非黑；只有 \(M=0\) 才表示黑色。令 \(u=H-B\)，精确逆式为 \(E=u(|u|+2B)=J_A|J_A|\)。实现单独携带这一带符号能量贯穿 Color，因此即使舍入后的 \(H\) 等于 \(B\)，极小的非彩值仍能保留。

调色平面以实际 \(C\) 作为半径。不要用教科书里的 CAM16-UCS \(M'\) 或其他压缩均匀空间坐标替代这些 \((a,b)\) 值。共享的术语并不意味着数值尺度可以互换。

在非负分支上，归一化明度为 \(j=H/100=M/100\)。参考白的中性色有 \(H=100\)；HDR 明度可以继续高于它。默认 Reference Nits = 203，适应亮度 \(L_A=20.3\) nit，暗环境常数为 \(c=0.525\) 与 \(N_c=0.8\)。编码与解码共用同一色相偏心率表达式，其中包含 \(-0.1475\sin h\)。

参考实现固定 \(Y_b=10\)，采用 Colour 中测试白为 \(Y_w=100\) 的尺度，并折现光源色。内部 XYZ 与白点 \(W\) 使用 \(Y=1\) 单位；归一化锥输入为 \((A\,XYZ)/(A\,W)\)，其中 \(A\) 是 CAT16 矩阵。背景设置与 20.3 nit 的适应亮度是不同的量。

完整解析 `Model` 接受 Grade 白点 D65、Reference Nits 203，与其缓存的边界上下文一致。底层外观与 Tone 辅助函数接受更宽的有效参考值范围。归档产品提供[工作白点](../guide/working-white.md)中描述的八种白点预设与 Reference Nits 控件；该产品界面不会扩大完整参考模型支持的上下文。

这一区别在负分支上很重要：Tone 重映射 \(M\)，保留 \(J_A\) 的符号，再重建 \(H\)。Color 的影调选择器同样使用 Tone 之后的 \(M\)。若将该幅值替换为带符号的 \(H\)，就会改变哪些影调控件影响该颜色。

[保持饱和度的影调曲线](tone.md) 在重映射明度的同时维持阶段 2 的不变量。[按影调塑形的色彩算子](color.md) 再按色调区域混合各项调整。[求值与插值](evaluation.md) 随后说明有界 H–K 保护以及解析、原生节点与采样三种实现。

当前 RGB 入口先执行阶段 1，再修复到原生 AP1 \([0,1024]^3\)，然后编码。外观辅助函数也直接支持带符号的锥响应。1.23.2 所描述的成对中性抬升、相减与分级回退属于历史行为。复位在合法输入立方体内保持恒等；立方体外的输入仍会经过入口修复。

阶段 3 依次执行 J/C 调整、Warp 色相／彩度、选择性 Adaptance、H–K 修复、公共正 Scale。默认启用保护时，非负 \(H\) 请求会修复，负 \(H\) 请求旁路修复；Scale 将任一携带能量乘以 \(\lambda^2\)，因此保持其符号。Appearance 交接携带这一策略处理后的状态，RGB 导出只执行独立的立方体保护。[保护章节](hk-guard.md)说明非负能量保证及其分支条件；[致谢](../reference/credits.md)列出模型参考文献。
