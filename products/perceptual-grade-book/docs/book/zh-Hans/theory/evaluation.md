# 求值与插值

这些方程定义一个 Grade。要在解析 DCTL、原生节点图与采样颜色表中产生相同结果，还需要有效的逆域与受控的数值近似。本章沿 Color 结束后到返回线性颜色的路径说明这些要求。

Color 系数之后，流水线中有四件不同的事，它们常被彼此混淆：

1. **H–K 修复**，对请求的外观对做定参考修复。它属于模型：每个实现都施加它，并且后续阶段看到的正是它的结果。
2. **解码**，外观编码的带符号逆，要求实数正非彩色能量与严格低于 400 极点的响应幅值。
3. **导出立方体保护**，投影到原生 AP1 RGB 上界，保持 \(J_A\) 与色相并缩减彩度。它只在导出时运行。
4. **采样求值**，用表查找与插值在有限个顶点上近似复合函数。

第 1、2 步是模型变换。第 3、4 步是另一类近似：保护是有意改变颜色，而表是以误差改变颜色。因此，两个表实现之间的一致性测量并不能说明其中任何一个与解析 Grade 一致。

[有界 H–K 保护](hk-guard.md)覆盖第 1、2 步，包括带符号能量路径与导出投影。其历史评估说明了当前保护是如何选定的，并把记录的实验与重新生成的对比分开。

[直接求值与采样求值](lut.md)覆盖第 4 步：扩展的曲线表、带符号 HDR 采样网格与物理线性 RGB 插值。它还把与采样器一致和与解析 Grade 一致区分开来：匹配的插值实现并不能消除颜色表的近似误差。

## 让两条路径使用同一组设置

同一组当前参数必须到达两条路径。已完成的 LUT 只对产生它的那个 Grade 有效；前向节点在准备期间使用 Direct，而逆向与 Stack 节点保留其先前完成的 LUT。一张表由其模型、尺寸、采样空间、地址常数以及每一个会改变函数的控件共同标识；其中任何一项变化都会使它失效，而不是用不同数值继续复用。

由此有两点推论，二者都曾造成真实缺陷：

- **过期的表绝不能当作当前结果呈现。** 如果无法完成替换，正确行为是保留 alpha 的可见失败，而不是静默回退并继续渲染先前的结果。
- **预览不是结果。** 粗预览以交互方式安装与更新，但最终渲染与正常保存需要完整的表。嵌套被安排成预览顶点是最终顶点的子集并被逐位复用，绝不使用不同的算术重算。

[运行时架构](../development/architecture.md)说明扩展在交互过程中如何维持这种一致，[完整规范](../development/forward-inverse-math.md)给出边界转换与逆向契约。
