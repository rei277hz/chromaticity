# 求值与插值

当前解析参考位于 `libraries/perceptual-grade-reference`。阶段 3 的顺序为明度／彩度系数行 → Warp 色相／彩度 → 选择性 Adaptance → H–K 修复 → 公共正值 Scale。冻结的 Blender 实现与归档的 1.23.2 DCTL 保留各自的顺序和控件。Next Blender 尚未提供 Warp 控件；未来实现应遵循修正后的参考模型。

## 从外观到 RGB

H–K 修复属于阶段 3 内部。它使用冻结的 Tone 后参考能量，在 Adaptance 之后、Scale 之前执行。对修复后的点，Scale 以 \(\lambda>0\) 把 \((a,b,E)\) 变为 \((\lambda a,\lambda b,\lambda^2E)\)。饱和度面板坐标 \((a,b)/\sqrt{C^2+|E|}\) 保持不变。在非负 H 的修复分支上，\(E\ge0\)；缩放后的 H–K 高度为 \(\sqrt{\lambda^2E+66\lambda C}\)，对每个非黑点随 Scale 严格增加。

`Model.grade_state` 返回已修复并缩放的外观。正向→逆向 Stack 衔接直接传递该状态，只跳过 RGB 立方体投影。`release_state(..., guard=False)` 直接解码所给状态；`guard=True` 只增加导出立方体保护。H–K 修复不是幂等操作，不应在导出或绘制面板时重复执行。

导出立方体保护通过实际解码器检查原生 AP1 RGB 是否位于 \([0,1024]^3\)。在正能量内部区间，它固定 \(J_A\) 与色相，缩减彩度直到解码合法。非正能量导出黑色；达到或超过立方体白点端点的能量导出立方体白色。响应幅值达到或超过 400 极点的解码试探会被拒绝。该投影可能在面板的外观空间保证之后改变饱和度，并且是有损的。

[有界 H–K 保护](hk-guard.md)给出修复方程、带符号能量处理与独立的导出策略。参考逆对每个候选求值完整正向函数，包括 Scale 之前的修复和最终立方体包含；它不会在搜索中嵌套一个独立的 H–K 逆。详见[参考逆契约](../development/forward-inverse-math.md#20-参考逆)。

## 近似完整函数

LUT 采样其所选配置的完整函数。输入修复、阶段 3 的 H–K 修复与 RGB 立方体包含都是函数的有意组成部分；有限采样和插值再引入近似误差。因此两个采样器彼此一致，并不能证明它们与解析调色一致。

[直接求值与采样求值](lut.md)说明原生 AP1 输入网格、输入修复、物理线性 RGB 插值以及各实现的曲线表。已记录的图和测量保留其生成时的旧实现范围，不能作为修正后 Warp 顺序的验证。

## 让结果对应其设置

完成的表只对生成它的设置和模型有效。签名包含模型版本、尺寸、采样空间、地址常数以及所有改变函数的控件。函数改变后必须生成替换表。

- **过期的表绝不能当作当前结果呈现。** 最后一次有效结果可以带更新标记继续显示。若当前内核无法构建或恢复，则应以保留 alpha 的洋红色输出明确报错。
- **预览必须标明为预览。** 交互过程中可更新粗表，最终渲染则需要已完成的当前结果。嵌套的 33³／65³ 网格逐位复用共同顶点。

当前 Next Blender 的发布与渲染预检契约由英文版开发部分的策略机器章节说明。[运行时架构](../development/architecture.md)与旧版逆向实现章节则按各自标注的范围保留历史行为。
