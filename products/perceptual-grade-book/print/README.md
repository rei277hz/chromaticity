# Print Editions

The PDF and EPUB are derived editions of the maintained English and Simplified
Chinese Markdown. The site remains the existing mdBook output. The print build
starts with mdBook's `print.html` for each edition, then adds front matter,
navigation, static KaTeX markup, print media, and the print or EPUB stylesheet.
There is no second Markdown renderer, and generated documents are not edited
by hand.

These editions follow the maintained handbook's scope: current-reference model
chapters alongside explicitly identified 1.23.2 usage and engineering material
that still needs updating. The title pages do not label the whole book as 1.23.2.

## Build and Check

Run from the monorepo root:

```sh
buck2 build --remote-only '//products/perceptual-grade-book:book[pdf]' --show-output
buck2 build --remote-only '//products/perceptual-grade-book:book[epub]' --show-output
buck2 test --remote-only //products/perceptual-grade-book/print:print //products/perceptual-grade-book/print:epub
buck2 build --remote-only //products/perceptual-grade-book/print:review --show-output
buck2 build --remote-only //products/perceptual-grade-book/print:policy_review --show-output
buck2 build --remote-only //products/perceptual-grade-book/print:chart_review --show-output
buck2 build --remote-only //products/perceptual-grade-book/print:chart_preview --show-output
```

The PDF output is A4 and uses fixed pagination, running heads, folios, and
chapter-level navigation. The EPUB is reflowable and splits content at chapter
boundaries. Both formats include English and Simplified Chinese. Their build
outputs live under Buck2's output directory; `print-manifest.json` records
chapter order, figures, tool versions, hashes, and the mdBook site manifest
hash.

Numerical plots are static PGFPlots SVGs shared with the website. Their text is
outlined for consistent rendering across browsers, WeasyPrint PDF, and EPUB
readers; localized image alt text and captions provide reader-facing context.
The original recorded LUT reports remain downloadable with their source data.

The PDFs use full Tinos and Noto Serif SC font files from a pinned Google Fonts
revision. Noto's full variable source is instantiated at weights 400 and 700
before layout. The English PDF uses Tinos; the Chinese PDF falls back to Noto
Serif SC for Chinese glyphs, including inside code. Do not substitute web font
shards: WeasyPrint 70 can assign different shards the same PDF font identity,
corrupting both visible glyphs and copied text. The renderer excludes the EPUB's
sharded CJK stylesheet from its in-memory PDF document.

The remote test checks embedded fonts, Chinese Unicode extraction (including
`参数纹理使用稳定容量`), and agreement between the PDF Unicode map and embedded
glyph IDs. EPUB retains its existing fonts.
Release still requires a visual review of Chinese line breaks, punctuation, and
dense paragraphs at A4 width; text extraction cannot judge those page-level
details.

The optional `:review` target renders the cover and the architecture passage
with its adjacent pages to PNG using pinned PDFium. Its `review.json` records
the PDF hash and physical page numbers. This is a raster review without OCR.
The `:policy_review` target similarly renders every page of the English Next
policy chapter, using its PDF outline to select the chapter boundaries.
The `:chart_preview` target builds an independent A4 PDF with one numerical
chart per page at its natural print size, plus 144 dpi PNGs and a manifest. Use
it while editing chart sources to check labels, legends, clipping, and spacing
without rebuilding the whole book.

The `:chart_review` target renders every migrated numerical-chart page in both
editions at 144 dpi. It matches generated HTML figure IDs to PDF destinations,
so the selection follows pagination changes. It also includes the page after
each historical placement chart to review candidate keys that flow over a page
boundary. The per-language manifests record
each chart, figure ID, PDF hash, and physical page number; the Chinese edition
contains 14 charts because its existing testing chapter omits the benchmark.
Both PDF builds and tests use `PAR_APPEND_LD_LIBRARY_PATH` to preserve the
pinned Pango/HarfBuzz libraries through Buck's Python launcher.

The site remains owned by `//products/perceptual-grade-book:site`. The print
target consumes that output and emits sibling PDF and EPUB output groups. Tests
compare the site manifest and stable deployment archive against the reviewed
site baseline. Update that baseline deliberately when authored content changes;
print layout changes alone must not alter the deployed site.

## Layout Ownership

Edit handbook prose, chapter ordering, and figures in `docs/book/`. Keep the
English and Simplified Chinese chapter paths aligned except for the declared
English-only Next policy-machines chapter. Its static D2 SVGs are generated by
`//products/perceptual-grade-book/diagrams:assets` and flow through the existing
site, PDF, and EPUB inputs. The edition-specific
cover, title page, copyright page, and colophon live in
`print/front-matter/<language>/front-matter.html`. Shared page tokens and the
print and reflowable EPUB skins live in `print/theme/`.

Tune the page grid, type, and spacing in the stylesheets while keeping the
authored Markdown unchanged. Review a representative set of pages before
building the complete editions: front matter, contents, a chapter opener, body
text, figures and captions, tables, callouts, code, and display equations. For
Simplified Chinese, check line breaks, punctuation placement, font coverage,
and dense paragraphs at A4 width. The chapter and figure lists, static math,
embedded PDF fonts, Chinese text extraction, page labels, archive determinism,
and unchanged site hashes are covered by the print acceptance tests.

Fonts, KaTeX, and their notices are pinned build inputs. The derived document
copies only referenced local images; historical downloads link to the published
site. Do not add animation, video, or script-driven controls to print content.
