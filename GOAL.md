## Numerical contract

Stage 3 order: apply J/C terms; apply Web hue/chroma and select the final positive Scale; apply selective Adaptance using frozen post-Tone selectors; run H-K repair using frozen post-Tone signed energy; apply Scale to repaired opponent coordinates and Scale squared to repaired energy. Do not perform another H-K repair after Scale.

Preserve reference behavior for negative-H guard bypass, zero chroma, zero reference energy, and neutral Scale. RGB cube containment remains the export boundary operation.

## Texture contract

Each bank carries five RGBA32F images: scalar/Tone parameters, Color coefficients, Web parameters, Web toes, and Adaptance parameters. The complete bundle is 2,916,976 bytes per bank and 5,833,952 bytes for both (about 5.56 MiB), excluding the shared boundary image. Adaptance always uses 32,768 cells packed into 8193×4 pixels (524,352 bytes per bank), under field layout schema 6. Stage and verify a complete candidate bundle before switching the shared selector. Reuse unchanged role payloads where the candidate image already has the required receipt. On failure, preserve existing rollback and fail-closed behavior.

Parameter schema 4 adds two texels within the existing 512×1 scalar image for tonal anchors and authored Adaptance-row activity. They preserve exact-zero cardinal support across atlas interpolation without tolerance masking; the scalar image's dimensions and byte size remain fixed.
